# 卡牌特效：打击 / 防御 / 出牌（2026-11-10 第三轮）

> 前两轮见 [`优化记录-2026-11-10.md`](优化记录-2026-11-10.md)、[`手感与转场-2026-11-10.md`](手感与转场-2026-11-10.md)。

## 先说"为什么你看不到特效"

不是错觉。把出牌过程逐帧录下来（`tools/fx_lab.gd`，`--fixed-fps 60`），
当时的 `now_attack` / `now_block` 两条：

- **打击**：只有一个 16px 的 `art/fx/hit.png` 星芒，在 5 倍放大的画面上约等于 3 个像素点；
- **防御**：**完全没有**——加格挡只有一个飘字。

![before](shots/fx/in_game_before.png)

所以上一轮我把 `hit-flash` / `shield-block` 加进来又撤掉，是有原因的，但原因找错了。

## 真正的原因：`meta.actor`

pixelfx 的效果里有一半是"**带演员**"的：`meta.actor` 非空时，效果会自己画一个原装小人
（配合它的动作表）。贴在**玩家身上**就是两个人在打架，贴在墙上就是一条红色竖条——
第一版 `hit-flash`（80×64，actor=2）看起来像"红色竖条"、`shield-block`（148×104，actor=2）
看起来像"蓝色圆罩盖住玩家"，都是这个原因，不是缩放问题。

选特效的第一条硬规则：**要叠在游戏角色身上的，必须 `meta.actor` 为空**。

| 效果 | 尺寸 | actor | 结论 |
|---|---|---|---|
| `impacts/hit-flash` | 80×64 | **有** | 弃（会画小人） |
| `impacts/shield-block` | 148×104 | **有** | 弃（会画小人+挡住玩家） |
| `impacts/blunt-hit` | 128×88 | 无 | ✅ 打击（普攻） |
| `impacts/crit-hit` | 216×136 | 无 | ✅ 打击（8 点以上） |
| `impacts/parry` | 200×112 | 无 | ✅ 防御（换 ice 调色板） |
| `spawn/poof` | 112×92 | 无 | ✅ 出牌消耗 |

## 现在的三处特效

| 时机 | 效果 | 位置 | 调色 | 缩放 |
|---|---|---|---|---|
| 伤害 ≥ 8 | `impacts/crit-hit` | 受击者 | 自带（暖） | 0.5 |
| 伤害 1–7 | `impacts/blunt-hit` | 受击者 | 自带（暖） | 0.5 |
| 加格挡 | `impacts/parry` | 玩家 | **ice（冷蓝）** | 0.5 |
| 出牌 | `spawn/poof` | 卡牌位置（UI 层） | 自带（白烟） | 0.55 |

打击和防御**刻意用了不同色温**：暖色=打人、冷色=挡。同一个紫色爆点出现在两边，
玩家分不清发生了什么。

## 为什么还要加"命中定格"

特效本身的亮部只有 **4–6 帧**（约 80–100ms）。就算做对了，一闪而过还是"没看见"。
所以加了 60ms 的 hit-stop：

```gdscript
# battle.gd，攻击牌结算后
Juice.hit_stop(0.06)
```

实现要点（这个不写对会把整个游戏搞死）：

```gdscript
func hit_stop(real_seconds := 0.06, freeze_scale := 0.02) -> void:
	if _hit_stop_on or not hit_stop_enabled:
		return
	_hit_stop_on = true
	var prev := Engine.time_scale
	Engine.time_scale = freeze_scale
	# 第 3 个参数 ignore_time_scale：否则计时器自己也被冻住，永远等不到放开
	await get_tree().create_timer(real_seconds, true, false, true).timeout
	Engine.time_scale = prev
	_hit_stop_on = false
```

- 必须放在 **autoload（Juice）** 里：它改的是全局 `Engine.time_scale`，
  一旦"恢复"的协程跟着场景一起被释放，游戏会永久停在 0.02 倍速。Juice 常驻，恢复一定跑得到。
- `_hit_stop_on` 防重入：一次出牌打了两个敌人，不会叠加成两次定格。
- 实测：冻结期内 `Engine.time_scale == 0.02`，90ms 后回到 `1.0`（见下方"验证"）。

副作用：截图/录制工具抓一帧要几十毫秒，会把定格录成"半路冻住"。所以
`tools/fx_lab.gd` 里把 `Juice.hit_stop_enabled = false`，录特效本身；
游戏里照常开。

## 顺带修掉的启动卡顿

上一轮我把 7 个转场全部预烘，实测 **4448ms** 白屏（原以为每个 90–140ms，实际平均 635ms）。
现在只预烘最常用的普通战斗转场：**130ms**。其余房间类型第一次进时现烘。

| 项 | 结果 |

## 怎么调

- 特效换不换：改 `Enemy.take_damage` / `Player.add_block` 里那两行 effect id；
  换之前**先看 `meta.actor`**，非空的一律不能贴在人身上。
- 大小：`{"scale": 0.5}`，0.5 是 2:1 干净缩小；0.75 会糊一档。
- 定格时长：`Juice.hit_stop(0.06)`，想要更"顿"就 0.09，想轻就 0.04。
- 重新录一遍对比图：`godot --fixed-fps 60 --path . -s res://tools/fx_lab.gd`，
  候选列表在 `fx_lab.gd` 顶部的 `ATTACK_CANDIDATES` / `BLOCK_CANDIDATES`。
