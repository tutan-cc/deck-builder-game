# 2D 美术资产清单

> 盘点时间：2026-11-09
> 依据：全项目 `res://art/**` 引用扫描 + 各 UI 场景节点结构
> 结论先行：**这个游戏的视觉问题是"信息只用文字表达"**，不是"缺素材"。

## 现状体检

| 指标 | 数值 |
|---|---|
| `art/` 下 PNG 总数 | 51 |
| 真正被场景/脚本引用的 | 18 |
| 未被任何地方引用（死资源） | 45 |
| 用纯 `Label` 表达的核心状态 | 血量、格挡、能量、金币、层数、状态、敌人意图 |

关键佐证：

- `stats_ui.tscn` 只有 `Health` / `Block` / `Statuses` **三个 Label**，没有任何图标节点。
- `intent_ui.tscn` 只有一个 `Label`，敌人意图是纯文本。
- `top_bar.tscn` 里能量是 `"0能"` 字符串，金币是 `"◆"` 字符。
- `map.gd` 的房间是 `24×16` 的程序绘制方框，没有房间图标。
- 卡背从未存在——牌堆/弃牌堆视图复用卡牌正面。

## 可清理的死资源

`art/tile_*.png` 共 40+ 张 Kenney 切片，除遗物数据里还挂着 4 张（`tile_0074/0084/0108/0124`）外已无引用。
而 `Relic.icon` 本身**从未被渲染**（`run.gd` 只拼文字），所以这 4 张实际也是死数据。

删除前建议先跑一遍游戏确认无缺失报错。

## 生成管线

所有已生成资产都由 `tools/` 下的 Aseprite 脚本产生，可重复运行：

```powershell
& "C:\Users\chris\AppData\Local\Programs\Aseprite\aseprite.exe" -b --script tools/gen_ui_icons.lua
```

| 脚本 | 产出 |
|---|---|
| `tools/gen_card_frames.lua` | `art/cards/card_frame_*.png` |
| `tools/gen_card_icons.lua` | `art/cards/icons/icon_*.png` |
| `tools/gen_actors.lua` | `art/actors/actor_*.png` |
| `tools/gen_ui_icons.lua` | `art/ui/*.png`（12 个图标 + 卡背） |

风格约定：1px 深描边 `K(26,22,26)` + 2~3 阶明暗 + 左上角高光，16×16 网格对齐。
