# pixelfx 全库选型：244 个特效里，哪些能用在这款游戏上

> 前三轮见 [`优化记录-2026-11-10.md`](优化记录-2026-11-10.md)、[`手感与转场-2026-11-10.md`](手感与转场-2026-11-10.md)、[`卡牌特效-2026-11-10.md`](卡牌特效-2026-11-10.md)。

## 先把库摸清楚

`addons/pixelfx/fx/` 一共 **244** 个效果，21 个分类（每类 10–13 个）：
arcane / critters / explosions / fire / holy / ice / impacts / lightning / melee / moves /
nature / pickups / projectiles / scifi / shadow / spawn / status / transitions / ui / water / weather。

我把每个的 `meta` 抽成一张表（`shots/fx/catalog.json`，244 行，字段：id / 名字 / 画布尺寸 /
时长 / 是否循环 / 是否带演员 / tags / 描述），然后按两条硬规则筛：

### 规则一：`meta.actor` 必须为空

库里 **73 个效果自带演员**——它们会自己画一个原装小人（配合内置动作表）。
贴在玩家/敌人身上就是"两个人在打架"。**这一条杀掉了一整类**：

| 分类 | 带演员的比例 | 后果 |
|---|---|---|
| `status/*` | **13/13 全部带演员** | 想做"易伤/虚弱/中毒"挂在敌人身上的常驻标记 —— **这条路直接堵死** |
| `holy/*` | 5/10（heal、divine-shield、halo、blessing、resurrection） | 常见的"护盾光环"都不能贴身上 |
| `spawn/*` | 5/10 | 碎裂死亡、消融、还魂都带人 |
| `melee/*`、`moves/*` | 几乎全带 | 那是"演一段动作"，不是"贴个特效" |

→ 剩下 **171** 个可以自由贴。

### 规则二：画布尺寸要配 256×144

游戏视口 256×144、精灵 16px。pixelfx 的画布是 320×180 一级的。
再筛"两边都 ≤160、时长 ≤2.5s"→ **51 个**，这些缩到 0.5 倍（正好 2:1）落在 8–80px 之间，能用。

## 房间转场：试过 pixelfx，撤了

一开始用 `transitions/pixel-dissolve`（0.8 倍铺满 256×144）做地图→房间的过场，
跑起来是这样的：**满屏 16px 碎块压住界面文字**，看着像花屏而不是过场。

原因：这类效果按 320×180、20px 格子作画，是"整屏当一张画"的思路；
而本工程是 16px 精灵 + 满屏 UI 文字，缩放后既糊又吵。

现在换成 `Juice.fade_transition(path)`：淡出 0.14s → `change_scene` → 淡入 0.18s。
好处是零烘焙（原来 7 个转场要 4.4s、单个也要 130ms），代价是没花样。

**结论：pixelfx 适合"一个角色身上的一瞬间"，不适合"整屏的空间转换"。**

## 状态标记：`status/*` 走不通，最后这么做的

`status/*` 13 个全带演员，不能用。所以分两层解决"玩家怎么知道敌人被挂了状态"：

**1. 挂上的一瞬间**——`Enemy.add_status` / `Player.add_status` 里炸一个 `impacts/hit-spark`，
按状态换调色板：

| 状态 | 调色板 | 读起来 |
|---|---|---|
| 易伤 vulnerable | `shadow`（紫） | 被诅咒/标记了 |
| 虚弱 weak | `ice`（蓝） | 被削弱了 |
| 力量 strength | `fire`（橙） | 变强了 |

用同一个形状换颜色，而不是找一个"状态特效"——这是**在尺寸/演员两条限制下唯一能用的做法**，
代价是它和"打击"同形状，所以颜色必须严格区分（暖=打人、紫/蓝=被标记）。

**2. 之后一直存在的**——UI 上的状态图标会"弹一下"：
`StatsUI._rebuild_statuses` 记录上一次的层数，只在**层数涨了**时把数字从 2× 缩回 1×
（`TRANS_BACK`，0.22s）。不这么做的话每次掉血都会重建节点、数字乱抖。

## 技能牌

没有加通用特效。库里"施法"类要么带演员、要么 208×150 起会盖住手牌。
现在的规则是：**技能牌只有真的挂了状态才有特效**（走上面那条 `add_status`），
纯抽牌/纯能量类的技能牌保持安静——不然一回合三四张技能牌，满屏都是花。


## 怎么自己再翻

```powershell
# 重新生成选型表（244 行 JSON）
#   id / name / w / h / dur / loop / actor / tags / desc
shots\fx\catalog.json

# 在真背景上预览任意候选（改 fx_lab.gd 顶部的 ATTACK_CANDIDATES）
godot --fixed-fps 60 --path . -s res://tools/fx_lab.gd
```

`fx_lab.gd` 的候选项支持 `scale` / `duration` / `on_player` 三个字段，
录出来是逐帧横条，能直接看清尺寸和可读性。

## 还能用、但这次的活没排进去

但会挡住交互提示，得单独试一轮再决定。
